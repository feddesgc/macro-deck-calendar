# Macro Deck Calendar

Macro Deck Calendar is a personal, non-commercial setup that connects the author's own Google Calendar to the open-source Macro Deck application running on the author's own computer. It is used only to show calendar information (for example upcoming events) on the author's personal Macro Deck control surface.

This project is not a public service, is not offered to other users, and is not affiliated with Google.

Read the [Privacy Policy](privacy.html).

App personal de uso propio: conecta el Google Calendar del autor con Macro Deck en su propia PC. No es un servicio publico.
