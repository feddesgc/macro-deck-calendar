# Privacy Policy - Macro Deck Calendar

Last updated: 2026-11-23

Macro Deck Calendar is a personal, non-commercial project used only by its author, who is also its only user. It connects the author's own Google Account to the Macro Deck application installed on the author's own computer.

## Data accessed

The application accesses the author's Google Calendar data (such as calendar and event information) only to display it on the author's personal Macro Deck interface.

## How data is used and stored

- Data is processed locally on the author's computer by the Macro Deck application.
- The OAuth credentials and tokens are stored only on the author's computer.
- No Google user data is transferred to, sold to, or shared with any third party, and no servers are operated by this project.
- Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page (https://myaccount.google.com/permissions). Removing the Google Calendar configuration in Macro Deck deletes the locally stored tokens.

## Contact

Questions can be sent by opening an issue in this GitHub repository.

## Politica de privacidad (resumen en espanol)

Proyecto personal de uso propio. Los datos de Google Calendar se usan solo para mostrarlos en el Macro Deck del autor, se procesan y guardan localmente y no se comparten con terceros.
